# Simbe Robotics

> Simbe (Simbe Robotics) is a physical-AI and retail-robotics company. Its Store Intelligence
> platform combines the Tally shelf-scanning robot, fixed in-store sensors and RFID to give
> retailers real-time inventory, pricing and shelf-condition data. Simbe operates an API that feeds
> that data into a retailer's existing merchandising and task systems, but publishes no public
> developer portal, API reference, or machine-readable specification.

## What an agent should know first

- **There is an API, and it is not public.** Simbe's own status page monitors an "API" component
  (99.91% uptime, May-Aug 2026) alongside "Website" and "App", so a production API demonstrably
  exists. Simbe's FAQ states: "We'll provide you our standard API documentation which will allow us
  to start feeding you the data." The contract is supplied to customers during an integration
  engagement. There is no public base URL, no OpenAPI, no GraphQL SDL, no AsyncAPI, no MCP server
  and no A2A agent card.
- **Do not guess a base URL.** As of 2026-08-27, `api.simberobotics.com`, `docs.simberobotics.com`,
  `developer.simberobotics.com`, `developers.simberobotics.com`, `app.simberobotics.com` and
  `cloud.simberobotics.com` all return NXDOMAIN. Only `www`, `status` and `trust` resolve.
- **Integration is a sales motion, not a self-serve signup.** There is no pricing page, no plans, and
  no developer signup. The entry point is the contact form.
